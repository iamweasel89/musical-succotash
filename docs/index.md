# Индекс документации hex-canvas-mobile

Каталог wiki по [схеме Карпати](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f): `CLAUDE.md` = schema (как устроено), этот файл = index (что где), остальные — wiki-контент. Читай нужное по запросу, не всё подряд.

## Манифест

- [docs/vision.md](vision.md) — что строим, для кого, принципы, чего НЕ строим

## Паспорт проекта

[PASSPORT.md](../PASSPORT.md) — основной живой документ. Разделы:

- **§ Метаданные** — репо, ветка, стек
- **§ Что приложение делает** — две вкладки + Мастерская
- **§ Протокол работы** — стиль общения, маркировка ответов/задач, ключевые слова, адаптация команд
- **§ Архитектура** — дерево `lib/`, модули
- **§ Что реализовано** — таблица статуса фич
- **§ Срочные задачи** — группы ПТ, РГ, Я
- **§ Бэклог** — группы У, О, К, П, ПО, Р, Н, З, Б, М, Т, БК, ЛЧ, ВИ, ОТ, МЦ, Ц, КФ, ВР, ПМ, УК, СТ, Р-рефакторинг, СП, ДЛ, Ш, Г, И
- **§ Сценарии** — СЦ-1..СЦ-8, операционные истории
- **§ Сырой резерв** — идеи без use-case
- **§ Ключевые концепции** — глоссарий
