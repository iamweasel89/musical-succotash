# Schema для Claude Code

Этот файл = **schema** по [модели Карпати](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f). Содержит: протокол работы + указатель на wiki. Контент живёт в [docs/index.md](docs/index.md) и по ссылкам оттуда. Не грузи PASSPORT автоматически — только по запросу из конкретной задачи.

## При старте сессии

1. Прочти [docs/index.md](docs/index.md) — каталог wiki.
2. Прочти последний файл из `sessions/` — контекст прошлой сессии и `last_n` для нумерации (если есть).
3. Если туннель `windows-3tm8vsu.tail60e676.ts.net` активен — дёрни `/state` + `/screen` чтобы увидеть текущее состояние приложения.
4. Читай PASSPORT, cases, sessions — **только по запросу** из задачи. По умолчанию они не в контексте.

## Нумерация ответов

В начале каждого ответа — вызови `TZ="Europe/Bratislava" date +"%Y-%m-%d %H:%M"` через Bash и выведи номер, дату и время в формате `**N. [YYYY-MM-DD HH:MM]**`.

Номер глобальный и монотонно растёт. При старте новой сессии — продолжай с `last_n+1`, где `last_n` берёшь из последнего файла `sessions/`. Если файла нет — стартуй с 1. После авто-компакшна счётчик стартует с 1 (восстановить невозможно).

Если в одном ходу несколько сообщений — нумеруется только первое, остальные без номера; ссылки по номеру первого.

## Очередь коммитов

Когда оператор говорит «добавь в очередь на коммит» — делай правку но НЕ коммить сразу. Копи мелочи, объединяй с следующим содержательным коммитом. Цель — меньше APK-сборок ради пары строк.

## Session log

В конце сессии (или при явной команде «сохрани сессию») — обнови/создай `sessions/YYYY-MM-DD.md`. Минимум: `last_n` + одна фраза о чём была сессия. Максимум: ключевые решения, что в очереди, контекст для следующей.

## Отладочный API (ОТ)

Туннель: `https://windows-3tm8vsu.tail60e676.ts.net` (Tailscale Funnel, поднимается вручную на windows-3tm8vsu — см. [docs/ops/tunnel.md](docs/ops/tunnel.md)).

Токен: `b728d014c3bdc1482a142135d2a114da` — меняется только кнопкой «Перегенерировать» в Мастерская → Отладка. Если запрос возвращает 403 — токен обновился, спросить у оператора.

Эндпоинты (все требуют X-Debug-Token):
- `/state` — общий срез: канвас, счётчики, экран, undo/redo
- `/screen` — текущий экран + стек + snapshot провайдера
- `/canvas` — ноды, рёбра, chain, pan/zoom
- `/settings` — провайдер, модель, ключи API (замаскированы), флаги UI
- `/logs`, `/theses`, `/decisions`, `/websearch` — дополнительные срезы
- `/screenshot` — PNG (не JSON)

Вместе дают полный срез системы.
