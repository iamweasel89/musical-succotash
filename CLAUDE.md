Читай PASSPORT.md перед началом работы.

Нумеруй свои ответы оператору. В начале каждого ответа — вызови `TZ="Europe/Bratislava" date +"%Y-%m-%d %H:%M"` через Bash и выведи номер, дату и время в формате `**N. [YYYY-MM-DD HH:MM]**`. Номер глобальный и монотонно растёт через всю сессию. После авто-компакшна счётчик стартует с 1 (восстановить номер невозможно — не угадываем). Если в одном ходу несколько сообщений — нумеруется только первое, остальные без номера; ссылки по номеру первого.

Когда оператор говорит «добавь в очередь на коммит» (или похожее) — делай правку но НЕ коммить сразу. Копи мелочи, объединяй с следующим содержательным коммитом. Цель — меньше APK-сборок ради пары строк.

## Отладочный API (ОТ)

Туннель: `https://windows-3tm8vsu.tail60e676.ts.net` (Tailscale Funnel, поднимается вручную на windows-3tm8vsu — см. docs/ops/tunnel.md).  
Токен: `b728d014c3bdc1482a142135d2a114da` — меняется только кнопкой «Перегенерировать» в Мастерская → Отладка. Если запрос возвращает 403 — токен обновился, спросить у оператора.  
Эндпоинты (все требуют X-Debug-Token):
- `/state` — общий срез: канвас, счётчики, экран, undo/redo
- `/screen` — текущий экран + стек + snapshot провайдера
- `/canvas` — ноды, рёбра, chain, pan/zoom
- `/settings` — провайдер, модель, ключи API (замаскированы), флаги UI
- `/logs`, `/theses`, `/decisions`, `/websearch` — дополнительные срезы
- `/screenshot` — PNG (не JSON)

Дёргать при старте сессии если туннель активен. Вместе дают полный срез системы.
