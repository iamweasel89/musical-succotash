# База кейсов проекта

Живой банк проектных решений и поворотных моментов разработки. Каждый кейс — отдельный markdown-файл с yaml frontmatter.

## Формат файла

```markdown
---
id: 001
title: Короткое название
seed: "Где / когда появилось семя (может быть другой диалог)"
germination: "Когда проросло"
trigger: "Что сдвинуло с семени на росток"
tags: [кирпич, пт, refactor]
links: [002, 003]
date: 2026-04-17
---

## Контекст

Что происходило.

## В запале

Что напрашивалось быстро.

## Выбрали

Что сделали вместо.

## Открыло

Какие зоны роста.

## Закрыло бы A

Что бы заблокировалось если бы пошли в запале.
```

## Именование файлов

`NNN-краткий-слаг.md` — трёхзначный порядковый + слаг. Пример: `001-compress-stal-pt.md`.

## Связи

Wikilinks в теле: `[[001]]` или `[[001-compress-stal-pt]]` — viewer отобразит как clickable.

## Совместимость

- **Obsidian:** открыть папку `cases/` как vault → сразу работает
- **VSCode / GitHub web:** читать/редактировать напрямую
- **hex-canvas:** Мастерская → Кейсы (read-only viewer)

## Порядок

Кейсы сортируются по `date` убыванию (свежие сверху). Для кейсов одного дня — по id. Git-история хранит момент создания и изменений.
